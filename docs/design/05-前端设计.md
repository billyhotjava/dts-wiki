# 05 前端设计（JHipster React）

## 1. 技术与结构
- JHipster 9 React 客户端：React 19、TypeScript、Redux Toolkit（`createAsyncThunk` + slice）、React Router、Bootstrap 5、`react-jhipster`（i18n、分页、格式化）、Vite（`clientBundler vite`）、Vitest。
- 默认语言 **zh-cn**（JDL `nativeLanguage`），同时提供 en；所有新文案进 `src/main/webapp/i18n/zh-cn/wiki*.json` 与 `en/`。
- 自定义代码全部放在 `src/main/webapp/app/modules/wiki/`，JHipster 生成的 `entities/` 仅作管理后台（`/admin/...` 菜单下）。

```
app/modules/wiki/
  api/            wiki-api.ts（axios，路径 /api/wiki/**；类型与后端 DTO 一一对应）
  store/          spaces.slice.ts, tree.slice.ts, page.slice.ts, search.slice.ts, notifications.slice.ts
  layout/         WikiLayout.tsx（顶栏 + 左侧页面树 + 正文）、SpaceSwitcher、GlobalSearchBox、NotificationBell
  tree/           PageTree.tsx（展开/折叠/拖拽/右键菜单）、TreeNodeActions.tsx
  page/           PageView.tsx、Breadcrumbs.tsx、PageMeta.tsx、MarkdownView.tsx、AttachmentsPanel.tsx
  edit/           PageEditor.tsx（编辑器封装）、ConflictBanner.tsx、DraftRestoreBanner.tsx
  history/        HistoryList.tsx、VersionDiff.tsx
  conflict/       ConflictMerge.tsx（三栏合并）
  comments/       CommentList.tsx、CommentEditor.tsx（@提及）
  search/         SearchPage.tsx
  home/           HomePage.tsx（我的空间、最近更新）、SpaceHome.tsx
  admin/          SyncAdmin.tsx（同步状态、deploy key、测试连接、立即同步、首次导入）、SpaceCreate.tsx
  templates/      TemplatePicker.tsx
```

- 页面树：虚拟滚动（上千节点）；当前页高亮并自动展开祖先；拖拽时显示落点指示线；右键/悬停菜单：新建子页、改名、移动到…、复制、删除。
- 同步徽标：`PENDING_PUSH` 灰色"同步中"、`CONFLICT` 红色"冲突"；GIT 页显示 git 图标与仓库路径（悬停显示完整 gitPath，点击打开 GitHub 文件页）。
- 四态：每个数据区块统一使用 `<AsyncSection loading error empty>`（骨架屏 / 错误重试 / 空状态引导）。

## 4. 编辑器（依 F0 spike 结论二选一：Milkdown Crepe 或 Vditor）
- 封装为 `<MarkdownEditor value onChange onUploadImage readOnly />`，**对外只暴露 Markdown 字符串**。
- 必须满足：打开后不做修改则 `onChange` 不触发、导出内容与输入字节一致（F0 验收）；YAML frontmatter 不进入编辑区，保存时原样拼回。
- 工具栏：标题、粗斜体、列表、任务、引用、表格、代码块、链接、图片上传、Mermaid、撤销重做、所见即所得/源码切换、全屏。
- 图片：粘贴/拖拽 → `POST /api/wiki/pages/{id}/attachments` → 插入返回的 `markdown`；预览时 `./assets/x.png` 通过 `/api/wiki/pages/{id}/raw/assets/x.png` 加载。
- 保存：Ctrl/⌘+S；带 `baseVersionNo`；409 版本冲突 → 弹窗"他人已修改"：[查看差异] [加载最新版本] [仍用我的版本覆盖（二次确认）]。
- 草稿：每 5 s（有变化时）`PUT /draft`；打开时若服务端草稿比当前版本新 → 横幅"发现未保存的草稿 [恢复] [丢弃]"。
- 编辑心跳：每 30 s `POST /editing`；他人正在编辑时横幅提示姓名。
- 离开页面有未保存修改 → `beforeunload` 提示。

## 5. 版本对比与冲突合并
- VersionDiff：`diff`（jsdiff）行级对比，两种视图：并排 / 统一；可切换"渲染对比"（两侧渲染后按块高亮）。
- ConflictMerge：三栏（基线 / wiki 版 / git 版，只读）+ 下方结果编辑区（CodeMirror 6，预填 `git merge-file` 结果，冲突块高亮），按钮：[采用 wiki 版] [采用 git 版] [保存合并结果]。

## 6. Markdown 渲染（MarkdownView）
- `markdown-it` + 插件：GFM 表格、任务列表、脚注、锚点标题、Mermaid（懒加载）、代码高亮（Shiki 或 highlight.js，懒加载语言）。
- 选项与现网 wiki 保持一致：`breaks: true`（单换行即换行）、`html: false`（禁用原始 HTML）。
- 链接改写：相对链接 `./x.md`、`../a/README.md` → 调 `resolve` 得到页面 id 后变成站内路由；`./assets/x.png` → 附件地址；外链新窗口打开。
- 右侧浮动目录（h2/h3），代码块复制按钮。

## 7. 视觉
- 延续现网 wiki 主色 `#2f6f5e`（Bootstrap 主题变量 `$primary`），支持暗色（`data-bs-theme="dark"`）。
- 正文最大宽度 880 px，中文字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`；代码 `JetBrains Mono, Consolas, monospace`。
- 所有可交互元素有 hover/focus 样式，键盘可达（树支持方向键）。
