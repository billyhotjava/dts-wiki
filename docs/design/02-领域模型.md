# 02 领域模型

实体定义以 `jhipster/dts-wiki.jdl` 为准（已用 generator-jhipster 9.2.0 `jdl --json-only` 校验通过）。
本文补充 JDL 无法表达的**不变量、索引与自定义 Liquibase 变更**。

## 1. 实体关系总览

```
Space 1─* SyncRoot 1─1 SyncState
  │          └─ mountPage ─► Page(FOLDER)
  1
  *
Page ─ parent ─► Page (树)      Page 1─* PageVersion      Page ─ currentVersion ─► PageVersion
  │ 1─* Attachment   1─* Comment(─ replies)   *─* Label
  │ 1─* SyncConflict(baseVersion, wikiVersion)
  └ PageDraft / PageWatch / Notification / ActivityEvent  ─► User(jhi_user, 由 Keycloak 登录同步)
SyncOutbox ─► Space, Page
```

## 2. 不变量（服务层必须保证，并有单元测试）

| # | 不变量 |
|---|--------|
| I1 | 每个 Space 有且只有一个根 FOLDER 页（`parent = null`），标题 = 空间名；其余页面 `parent` 非空 |
| I2 | `Page.currentVersion` 总是该页 `versionNo` 最大的版本；FOLDER 页可以没有版本（无 README 时） |
| I3 | `PageVersion` 不可修改、不可删除（JDL `readOnly`；恢复旧版本 = 新增一个 RESTORE 版本） |
| I4 | 同一 Space 内 `gitPath` 唯一（未删除的页面之间）；`kind=GIT` ⇔ `gitPath` 以 `.md` 结尾且位于某个启用的 SyncRoot 之下；`FOLDER` 在同步根内时 `gitPath` 为目录路径（无尾斜杠） |
| I5 | 页面的 `space` 与其父页面相同；移动不能跨空间（跨空间 = 复制 + 删除，v1 不做） |
| I6 | 不能把页面移动到自己的子孙节点下 |
| I7 | `syncStatus`：NATIVE/TEMPLATE 页恒为 `LOCAL_ONLY`；GIT/同步根内 FOLDER 页只能在 `SYNCED`/`PENDING_PUSH`/`CONFLICT` 之间迁移（见 04） |
| I8 | 一个页面同时最多一条未解决的 `SyncConflict` |
| I9 | `contentSha256 = sha256(contentMd 的 UTF-8 字节)`；内容相同不产生新版本 |
| I10 | 软删除（`deletedAt`）的页面不出现在树、检索、最近更新中；回收站保留 30 天后由定时任务物理删除（GIT 页此时仓库中已 `git rm`） |

## 3. 自定义 Liquibase 变更（放在 `src/main/resources/config/liquibase/changelog/` 的自定义文件中，文件名以 `9000_` 开头，排在 JHipster 生成的变更之后）

```sql
-- 9000_extensions.xml
CREATE EXTENSION IF NOT EXISTS pg_bigm;          -- 若 F0 spike 选 zhparser，此处替换

-- 9001_constraints.xml
CREATE UNIQUE INDEX ux_page_space_gitpath ON page (space_id, git_path)
  WHERE git_path IS NOT NULL AND deleted_at IS NULL;
CREATE UNIQUE INDEX ux_page_version_no ON page_version (page_id, version_no);
CREATE UNIQUE INDEX ux_page_root ON page (space_id) WHERE parent_id IS NULL;           -- I1
CREATE UNIQUE INDEX ux_conflict_open ON sync_conflict (page_id) WHERE resolved_at IS NULL; -- I8
CREATE UNIQUE INDEX ux_draft_user_page ON page_draft (page_id, user_id);
CREATE UNIQUE INDEX ux_watch_user_page ON page_watch (page_id, user_id);
CREATE UNIQUE INDEX ux_syncroot_path ON sync_root (space_id, repo_path);
CREATE INDEX ix_page_tree ON page (space_id, parent_id, position) WHERE deleted_at IS NULL;
CREATE INDEX ix_outbox_pending ON sync_outbox (space_id, id) WHERE status = 'PENDING';
CREATE INDEX ix_activity_space_time ON activity_event (space_id, created_at DESC);
CREATE INDEX ix_notification_unread ON notification (recipient_id, created_at DESC) WHERE read_at IS NULL;

-- 9002_search.xml   检索文档：每页一行，只含最新版本
CREATE TABLE page_search_doc (
  page_id    bigint PRIMARY KEY REFERENCES page(id) ON DELETE CASCADE,
  space_id   bigint NOT NULL REFERENCES space(id),
  title      text   NOT NULL,
  body       text   NOT NULL,          -- 去掉 Markdown 标记后的纯文本
  updated_at timestamptz NOT NULL
);
CREATE INDEX ix_search_title ON page_search_doc USING gin (title gin_bigm_ops);
CREATE INDEX ix_search_body  ON page_search_doc USING gin (body  gin_bigm_ops);
CREATE INDEX ix_search_space ON page_search_doc (space_id);

-- 9003_shedlock.xml   ShedLock 表（定时任务单实例锁）
CREATE TABLE shedlock (name varchar(64) PRIMARY KEY, lock_until timestamp NOT NULL,
                       locked_at timestamp NOT NULL, locked_by varchar(255) NOT NULL);
```

说明：
- `page_search_doc` 不作为 JHipster 实体（无 REST），由 `SearchIndexService` 用 `JdbcTemplate` 维护。
- JHipster 生成的 `fake-data` 仅用于 `dev` profile，生产 profile 关闭（`spring.liquibase.contexts=prod`）。
- 版本表体量估算：现有约 200 个 md，平均 20 KB；导入最近 20 个历史版本 ≈ 80 MB，可接受。

## 4. 字段约定

| 约定 | 说明 |
|------|------|
| 时间 | 全部 `Instant`（PG `timestamp`，JHipster 默认 UTC）；前端按 `Asia/Shanghai` 显示 |
| `TextBlob` | JHipster 在 PG 上生成 `text` 列 |
| 位置 `position` | 同一父节点内整数排序，初始步长 1000；插入到两者之间取中值，空间不足时整组重排 |
| 作者 | `PageVersion.author` 关联 `jhi_user`（wiki 用户）；git 入站版本若按邮箱或登录名匹配不到用户，则 `author = null`，仅保留 `authorName`/`authorEmail` |
| `gitPath` | 仓库内相对路径，POSIX 分隔符，保留中文；同步根前缀包含在内（如 `worklog/v1.0.0/sprint-queue.md`） |

## 5. 首次导入时的数据映射（详见 04 §6）

| 仓库内容 | wiki |
|----------|------|
| 同步根目录 `worklog/` | FOLDER 页（mountPage），挂在空间根下 |
| 子目录 `sprint-5-202610/` | FOLDER 页，`gitPath = worklog/v1.0.0/sprint-5-202610` |
| 目录中的 `README.md` | 该 FOLDER 页的正文版本（FOLDER 页 `gitPath` 仍为目录；正文文件路径 = `<目录>/README.md`） |
| 其他 `*.md` | GIT 页，标题取首个 `# ` 标题，没有则取文件名 |
| 图片、pdf、pptx 等 | Attachment，归属同目录的 FOLDER 页（或同名 md 页），`gitPath` 为文件路径 |
